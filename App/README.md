# Paket Rekomendasi Aplikasi: Disertasi Henky (Edukasi Pencegahan IMS)

Berdasarkan: Proposal Penelitian henky 18 juli 2026 (2) (3).doc

| File | Isi |
|---|---|
| Rekomendasi Aplikasi Edukasi IMS - Kajian Teknis.docx | Laporan lengkap: ringkasan disertasi, konsep aplikasi, tech stack, struktur, PRD, desain, etika/distribusi, catatan perbaikan naskah proposal, roadmap |
| prd.md | Product Requirements Document (fitur P0/P1, peran, metrik, NFR) |
| struktur.md | Arsitektur, tech stack, struktur repo, skema database, alur kunci |
| task.md | Breakdown pekerjaan per fase dengan ceklis (siap dipakai untuk memandu pengembangan) |
| design.md | Panduan UI/UX (visual, bahasa, privasi, aksesibilitas) |

Cara pakai: ketiga file .md bisa langsung ditaruh di folder `docs/` repo aplikasi dan dijadikan konteks untuk pengembangan (termasuk bila dikerjakan dengan bantuan AI coding agent). File .docx untuk diskusi dengan promotor dan tim disertasi.

Catatan penting: sebelum implementasi, rapikan dulu inkonsistensi naskah proposal (bagian 8 di file .docx), terutama jumlah sampel, sisa teks dari naskah lain (WhatsApp/kualitas hidup), dan keputusan instrumen in-app vs Google Form.
